# residencia-experimentos

Experimentos da semana 9: aprendizado federado em dois cenários.

## Pastas

- **`artigos/reconfigmed/`** — reprodução do RECONFIGMED-CHAIN (Delhibabu, 2026) no WUSTL-EHMS-2020:
  análise de vazamento de rótulo e de atalho nas features, split ordenado contra aleatório, FedAvg,
  agregação por atenção e privacidade diferencial.
- **`bdg2-fl/`** — FedAvg no Building Data Genome Project 2, com cada site como um cliente: análise
  exploratória dos dados e comparação do FedAvg com treino centralizado e com um random walk.

Cada pasta é um projeto `uv` independente, com o próprio README.
